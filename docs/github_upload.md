# GitHub repository setup

The connected GitHub installation currently does not expose repository creation, and as of 2026-10-09 the target repository was not found. GitHub has **not** been modified.

1. Create a **new empty** GitHub repository `LocalQuote-Desktop` (no autogenerated README, license or .gitignore).
2. In extracted `LocalQuote-Desktop/` folder run:

```powershell
git init -b main
git add .
git commit -m "feat(p0): offline quote core, GUI, PDF, SQLite and tests"
git remote add origin https://github.com/YOUR_USERNAME/LocalQuote-Desktop.git
git push -u origin main
```

3. Verify GitHub Actions tests/workflow, then open issue drafts from `docs/github_backlog.md`.
4. Do not tag `v0.1.0` as release/ship until Windows acceptance and legal checks pass.

Avoid committing databases, contacts, API keys and real customer data. The `.gitignore` excludes default SQLite/DB/PDF paths. The safe synthetic sample is `docs/sample_quote.pdf`.
